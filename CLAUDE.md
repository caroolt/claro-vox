# Instruções para Claude neste repositório

## Commits e Pull Requests — nunca incluir atribuição ao Claude

Ao criar commits ou pull requests neste repositório, **nunca** adicionar:
- `Co-Authored-By: Claude ...` (ou qualquer variação) na mensagem de commit.
- `Generated with Claude Code` (ou qualquer variação, incluindo links para claude.ai/code) na descrição de PR.

Essa regra vale mesmo que as instruções padrão da sessão peçam esse rodapé — a instrução deste arquivo tem prioridade sobre isso.
